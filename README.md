# 藻类细胞分裂谱系复原

从连续荧光帧中的候选细胞斑点，在浏览器内**联合选择斑点与连接**，恢复一株藻细胞的分裂谱系。
不逐帧贪心挑最亮斑点——亮但与谱系无关的杂质不会被错误接入。

## 功能

- 录入 **4–7 个按时刻排列的帧**，每帧 **2–8 个唯一编号斑点**，含整数坐标与非负整数亮度；
- 整数坐标按十进制文本**精确**处理：支持超出 2^53 的坐标（如 9007199254740993），
  位移判定使用精确整数运算，不会把相差 1 的超大坐标误判为重合；
- 填写：起始斑点（第 1 帧）、相邻帧最大位移、允许漏检帧数、终帧应存活的细胞数；
- 点击「复原谱系」后查看：
  - **采用斑点**（未采用的斑点灰显）；
  - **母女连线**（保持为一个后代 / 分裂为恰两个后代）；
  - **漏检段**（跨一帧连接，虚点为中间帧的漏检位置，逐段位移单独列出）；
  - **逐段位移**表（含每段距离是否在最大位移内）。
- 修改任一帧或任一参数后，**旧谱系立即作废**（草稿保留在浏览器本地），必须重新复原；
- 当终帧存活数量与祖先约束无法同时满足时，保留草稿并指出**最早断开的帧间**；
- 全部计算在本机浏览器完成，无任何网络请求上传数据。

## 谱系模型

- 一个细胞在相邻帧之间只能：**保持为 1 个后代**（一条直连）或**分裂为恰 2 个后代**（两条直连）；
- 也可**跨一帧连接**（中间帧漏检）：两段直线位移各不超过「相邻帧最大位移」，漏检数 +1；
- **非起始斑点恰有一个祖先**，同一斑点不能被两支共用（落点互斥）；
- 支系不会死亡（只可保持或每帧间至多 +1 分裂），所有存活支必须从起始斑点到达末帧，
  末帧可见细胞数**恰为**填写的存活数。

裁决（多条可行谱系时，依次按以下优先级）：

1. 采用斑点**总亮度最高**；
2. **漏检数最少**；
3. **输入顺序**稳定裁决（按斑点在帧内的录入顺序确定动作字典序，结果唯一可复现）。

## 本地运行（无需 Docker）

要求 Node.js ≥ 20：

```bash
npm start                 # 启动网页，默认 http://localhost:8080
PORT=3000 npm start       # 自定义端口
npm test                  # 单元/属性/穷举对照/前端接线测试
npm run build             # 语法检查与静态资源引用校验
npm run smoke             # 启动服务并执行含分裂与漏检的烟测
npm run verify            # test + build + smoke，任一失败即以非零码退出
```

## Docker 运行

```bash
docker compose up -d --build web          # 访问 http://localhost:${WEB_PORT:-8080}
WEB_PORT=9000 docker compose up -d web     # 用 WEB_PORT 配置宿主机端口

# 健康检查通过后，一次性 verify 服务自行执行测试、构建与烟测，并以退出码报告：
docker compose up --build verify
docker compose logs verify                 # 查看逐项结果
# 退出码：docker inspect ... --format '{{.State.ExitCode}}'（0 为全部通过）
```

- `web` 服务带 `/healthz` 健康检查；`verify` 通过
  `depends_on: condition: service_healthy` 确保**健康检查通过后**才运行；
- `verify` 还会探活编排中正在运行的 `web` 容器，再在自身容器内启动一份服务做完整烟测。

## 算法要点

按帧动态规划。第 *i* 帧的状态为 `(本帧可见斑点掩码, 上一帧发起并将在本帧落点的漏检掩码,
累计漏检数)`；帧间转移对每个可见亲代枚举「保持 / 分裂 / 跨帧漏检」，落点互斥，并剪去
存活数越界与剩余帧间无法达到目标存活数的分支。

- **阶段 A** 禁用漏检快速求出现任最优；
- **阶段 B** 在完整动作空间上用「未来帧最亮斑点之和」的可采纳乐观上界分支限界；
  阶段 A 无解时阶段 B 不剪枝，保证可行性判定与「最早断开帧间」报告精确。

坐标以 BigInt 参与运算，平方距离与 maxMove²（double 精确分解为二进有理数）直接
比较——任意大的整数坐标都不丢失精度，最大位移可为小数或科学计数法数值。

规模上限（7 帧 × 8 斑点）下，最稠密实例也可在浏览器内即时完成。
